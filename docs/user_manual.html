01

시작하기 — 회원가입 및 로그인

회원가입

1
회원가입 페이지 접속로그인 화면 하단의 '회원가입' 링크를 클릭합니다.
2
필수 정보 입력아이디, 이름, 이메일, 조직명, 직책을 입력합니다.
3
비밀번호 입력 및 확인 v1.3 신규비밀번호를 입력하고, 비밀번호 확인 란에 동일한 비밀번호를 다시 입력합니다. 두 값이 일치해야 가입이 가능합니다.
4
관리자 승인 대기가입 완료 후 관리자 승인을 기다립니다. 첫 번째 가입자는 자동으로 관리자 권한이 부여되어 즉시 사용 가능합니다.
5
로그인승인 완료 후 아이디와 비밀번호로 로그인합니다.
v1.3 신규 — 비밀번호 마스킹 토글
비밀번호 입력란 우측의 눈 아이콘을 클릭하면 입력한 비밀번호를 확인하거나 다시 숨길 수 있습니다. 비밀번호 확인 란에도 동일하게 적용됩니다.
아이디와 비밀번호에는 한글을 사용할 수 없습니다. 영문, 숫자, 특수문자만 입력 가능합니다.

로그인

항목설명
아이디가입 시 등록한 아이디 (영문/숫자)
비밀번호가입 시 설정한 비밀번호 (최소 4자)
로그인 상태 유지체크 시 브라우저를 닫아도 30일간 로그인 유지

비밀번호 찾기

1
비밀번호를 잊으셨나요? 클릭로그인 화면 하단 링크를 클릭합니다.
2
가입 이메일 입력가입 시 등록한 이메일 주소를 입력하고 '재설정 링크 발송'을 클릭합니다.
3
이메일 확인받은 편지함에서 재설정 링크를 클릭합니다. 링크는 1시간 동안 유효합니다.
4
새 비밀번호 설정새 비밀번호를 입력하고 저장합니다.
재설정 이메일이 도착하지 않으면 스팸 편지함을 확인하거나, 등록된 이메일 주소가 맞는지 확인하세요.
02

대시보드 — 프로젝트 관리

대시보드 구성

로그인하면 대시보드가 표시됩니다. 내 프로젝트 목록이 조직별로 구분되어 표시되며, 다른 사용자가 공개한 프로젝트도 조회할 수 있습니다.

구성 요소설명
좌측 사이드바조직별 프로젝트 목록, 검색, 질의응답 메뉴, 로그아웃
내 프로젝트본인이 생성한 프로젝트 목록
공개 프로젝트다른 사용자가 공개로 설정한 프로젝트 (읽기 전용)

프로젝트 생성

1
새 프로젝트 클릭좌측 사이드바 하단의 '＋ 새 프로젝트'를 클릭합니다.
2
프로젝트 정보 입력프로젝트명(필수), 설명, 수행 조직명, 사업 담당자, 수행 담당자, 공개 여부를 입력합니다.
3
생성 완료생성 버튼을 클릭하면 프로젝트 상세 페이지로 이동하며, 6단계 분석을 바로 시작할 수 있습니다.

프로젝트 공개/비공개 설정

프로젝트 상단의 공개 여부 토글 버튼으로 언제든지 변경할 수 있습니다.

설정설명
비공개 (기본값)본인만 열람 및 편집 가능
공개모든 로그인 사용자가 조회 가능 (편집은 소유자만 가능)

프로젝트 카드 정보 v1.4 개선

대시보드의 프로젝트 카드가 넓어지고, 프로젝트 생성 시 입력한 담당자 정보가 카드에 표시됩니다.

카드 정보설명
프로젝트명프로젝트 이름
조직명수행 조직명
사업담당사업을 총괄하는 담당자 이름 (입력 시 표시)
수행담당실무 수행 담당자 이름 (입력 시 표시)
최종 수정일마지막으로 수정된 날짜
프로젝트 생성 또는 편집 시 사업담당·수행담당 필드를 채워두면 대시보드에서 바로 확인할 수 있어 편리합니다.

사이드바 토글 v1.4 신규

좌측 사이드바를 접어 작업 화면을 더 넓게 사용할 수 있습니다.

1
토글 버튼 클릭사이드바 상단의 ‹ 버튼을 클릭하면 사이드바가 아이콘 모드(64px)로 축소됩니다.
2
메뉴 사용축소된 상태에서도 각 아이콘 위에 마우스를 올리면 메뉴 이름이 표시됩니다.
3
펼치기다시 › 버튼을 클릭하면 사이드바가 원래 크기로 복원됩니다.
접기/펼치기 상태는 브라우저에 저장됩니다. 다음에 접속해도 마지막 상태가 유지됩니다.
사이드바 폭은 경계선을 드래그하여 자유롭게 조절할 수도 있습니다.
03

6단계 사업모델 분석 모듈

각 프로젝트는 아래 6단계 모듈로 구성됩니다. 순서대로 작성하는 것을 권장하지만, 언제든지 원하는 단계부터 시작할 수 있습니다. 상단 탭 네비게이션에서 각 단계로 이동합니다.

Step 01

사업 정의

사업의 기본 틀을 명확히 정의합니다.

  • 사업 도메인
  • 핵심 제품·서비스 범위
  • 매출 구조 및 주요 고객군
  • 기업 규모 및 보유 역량
  • 해결하려는 고객 문제
Step 02

환경 분석 v1.3 개선

5개 프레임워크로 환경을 분석합니다.

  • PESTEL 분석
  • Porter's 5 Forces 분석
  • SWOT 분석
  • VRIO 분석
  • 고객 세그먼트 맵
Step 03

가치 설계

고객에게 전달할 핵심 가치를 설계합니다.

  • 핵심 제품/서비스
  • 차별화 포인트
  • 고객 경험 여정
  • 핵심 자원·활동·파트너십
Step 04

수익 구조

수익 모델과 비용 구조를 정의합니다.

  • 수익 모델 유형
  • 가격 전략
  • 고객 획득 채널
  • 비용 구조 / 단위 경제성
  • 수익성 목표
Step 05

실행 체계

구체적인 실행 계획을 수립합니다.

  • 실행 로드맵
  • 핵심 성과지표 (KPI)
  • 조직 및 역할
  • 필요 자원·예산
  • 리스크 및 대응 방안
Step 06

검증·정제

가설을 검증하고 비즈니스 모델을 개선합니다.

  • 검증 가설 (핵심 가정)
  • 검증 방법 (MVP/실험)
  • 수집된 데이터/피드백
  • 학습 및 인사이트
  • 피벗 또는 개선 사항

입력 패널 토글 v1.4 신규

각 모듈 화면은 좌측 입력 패널과 우측 AI 분석 결과 패널로 구성됩니다. AI 분석 결과를 전체 화면으로 보고 싶을 때 입력 패널을 숨길 수 있습니다.

1
‹ 버튼 클릭AI 분석 결과 패널 상단의 ‹ 버튼을 클릭합니다.
2
입력 패널 숨김좌측 입력 패널이 숨겨지고 AI 분석 결과 화면이 전체 너비로 확장됩니다.
3
복원다시 › 버튼을 클릭하면 입력 패널이 다시 나타납니다.
입력 패널 접기/펼치기 상태도 브라우저에 저장됩니다. 모든 모듈에서 동일하게 적용됩니다.

데이터 입력 및 저장 (공통)

1
모듈 탭 클릭프로젝트 상세 화면 상단에서 원하는 단계 탭을 클릭합니다.
2
입력 필드 작성각 항목에 내용을 입력합니다. 최대 2,000자까지 입력 가능하며, 우측 하단에 남은 글자 수가 표시됩니다.
3
💾 저장 클릭작성 완료 후 저장 버튼을 클릭합니다. 저장하지 않은 내용은 페이지 이동 시 유실됩니다.
입력 데이터는 반드시 저장 후에 AI 분석에 사용됩니다. AI 분석 전 저장을 확인하세요.

환경 분석(Step 02) 서브모듈 사용법 v1.3 개선

환경 분석은 PESTEL, 5 Forces, SWOT, VRIO, 고객 세그먼트 맵의 5개 서브모듈로 구성됩니다. 상단의 탭 버튼을 클릭하여 각 서브모듈로 이동합니다.

1
서브모듈 탭 선택PESTEL, 5 Forces, SWOT, VRIO, 고객 세그먼트 맵 중 원하는 탭을 클릭합니다.
2
데이터 입력 후 저장해당 프레임워크에 맞게 내용을 작성하고 각 탭의 '💾 저장' 버튼을 클릭합니다.
3
AI 분석 실행저장 완료 후 '🤖 AI 분석' 버튼을 클릭합니다. 스타일 선택 모달이 표시됩니다.
4
분석 완료 확인분석이 완료된 탭에는 ✓ 뱃지가 표시됩니다.
각 서브모듈은 독립적으로 저장·분석됩니다. 다른 탭의 데이터나 분석 결과에 영향을 주지 않습니다.
04

AI 분석 기능 활용

Claude AI를 활용한 세 가지 분석 기능을 제공합니다. 각 기능의 목적과 사용 시점이 다르므로 상황에 맞게 활용하세요.

기능버튼사용 시점
AI 자동 데이터 입력✦ AI 자동 데이터 입력처음 시작할 때 — 빈 필드를 AI가 초안으로 채워줍니다.
AI 분석 실행🤖 AI 분석데이터 저장 후 — 입력된 내용을 기반으로 분석 보고서를 생성합니다.
필드별 AI 질문✦ AI에게 물어보기특정 항목 작성 중 — 해당 필드에 대해 개별 질문합니다.

AI 자동 데이터 입력

1
✦ AI 자동 데이터 입력 클릭모듈 상단의 버튼을 클릭합니다.
2
추가 정보 입력 (선택사항)팝업창에 추가 컨텍스트를 입력합니다. 프로젝트 정보(이름, 조직명, 설명)는 자동으로 포함되므로 입력하지 않아도 됩니다.
3
✦ AI 자동 입력 시작 클릭잠시 후 AI가 작성한 초안이 각 입력 필드에 자동으로 채워집니다.
4
검토 후 저장AI가 작성한 내용을 검토하고 필요한 부분을 수정한 뒤 저장합니다.
AI 자동 입력은 초안 작성 용도입니다. 실제 사업 상황에 맞게 반드시 검토하고 수정하세요.

AI 분석 실행 — 스타일 선택 모달 v1.3 신규

AI 분석 버튼을 클릭하면 분석 스타일을 선택하고 추가 지시사항을 입력할 수 있는 모달 창이 표시됩니다.

1
데이터 저장 확인입력 데이터가 저장되어 있어야 합니다. 저장하지 않은 경우 AI는 이전에 저장된 데이터를 분석합니다.
2
🤖 AI 분석 버튼 클릭스타일 선택 모달이 표시됩니다.
3
분석 스타일 선택빠른 선택 버튼 중 하나를 클릭하거나, 텍스트 영역에 직접 지시사항을 입력합니다.
4
🤖 AI 분석 시작 클릭분석이 시작됩니다. 완료까지 30초~2분 정도 소요됩니다.

분석 스타일 빠른 선택

기본 간결하게 상세하게 경영진 보고용 실행 중심
스타일특징추천 상황
기본표준 컨설팅 보고서 형식일반적인 분석이 필요할 때
간결하게핵심 인사이트와 전략적 시사점 위주요점만 빠르게 파악하고 싶을 때
상세하게근거와 수치 예시 포함, 깊이 있는 분석세부 내용까지 철저히 분석할 때
경영진 보고용Executive Summary 형식, 의사결정 중심경영진에게 보고할 자료를 만들 때
실행 중심액션 아이템과 우선순위 중심실행 계획 수립에 바로 활용할 때
빠른 선택 버튼을 클릭하면 해당 스타일의 지시사항이 자동으로 입력됩니다. 텍스트 영역에서 직접 추가 수정도 가능합니다.
추가 지시사항 예시:
· "스타트업 관점에서 분석해줘"
· "경쟁사 대비 차별화 포인트를 강조해줘"
· "표 형식으로 정리해줘"
· "리스크 요인을 더 자세히 분석해줘"

필드별 AI 질문

1
✦ AI에게 물어보기 클릭각 입력 필드 우측의 버튼을 클릭합니다.
2
질문 입력해당 항목과 관련된 질문을 자유롭게 입력합니다.
예: "우리 회사가 IT 스타트업인 경우 어떤 내용을 작성하면 좋을까요?"
3
답변 확인 및 적용AI 답변을 확인하고 '↩ 필드에 적용' 버튼을 클릭하면 해당 필드에 자동 입력됩니다. 또는 원하는 부분만 드래그하여 복사할 수 있습니다.
05

파일 저장 및 다운로드

작성한 데이터와 AI 분석 결과를 PDF로 다운로드할 수 있습니다. 총 3가지 저장 방식을 제공합니다.

파일 저장 종류

종류버튼 위치포함 내용
단계별 파일 저장각 모듈 우측 상단 '📄 단계 파일 저장'해당 단계 입력 데이터 + AI 분석 결과
서브모듈 파일 저장환경분석 각 서브탭 우측 '📄 파일 저장'해당 서브모듈 입력 데이터 + AI 분석 결과
전체 통합 보고서프로젝트 상단 '📋 전체 파일 저장'6단계 전체 입력 데이터 + AI 분석 결과

파일명 형식

종류파일명 예시
단계별{프로젝트명}_Step02_환경분석_051514.pdf
서브모듈{프로젝트명}_Step02_5Forces분석_051514.pdf
전체 통합{프로젝트명}_비즈니스모델설계_통합보고서_051514.pdf
파일명 끝의 숫자(예: 051514)는 월일시(05월 15일 14시) 형식입니다. 같은 날 여러 번 다운로드해도 파일명이 겹치지 않습니다.
AI 분석을 실행하지 않은 단계는 입력 데이터만 포함됩니다. 분석 결과를 PDF에 포함하려면 먼저 AI 분석을 실행하고 결과가 화면에 표시된 것을 확인하세요.
06

질의응답(Q&A)

사업 전략에 관한 질문을 등록하고 Claude AI로부터 전문적인 답변을 받을 수 있습니다. 프로젝트와 연계하면 AI가 사업 맥락을 이해하고 더 정확한 답변을 제공합니다.

새 질문 작성

1
질의응답 메뉴 클릭좌측 사이드바의 '💬 질의응답'을 클릭합니다.
2
새 질문 작성제목과 질문 내용을 상세히 입력합니다.
3
관련 프로젝트 선택 (선택사항)질문과 관련된 프로젝트를 선택하면 AI가 해당 프로젝트의 사업 정의, 전략 정보를 참고하여 더 맞춤화된 답변을 제공합니다.
4
저장 + AI 답변 요청버튼을 클릭하면 질문이 등록되고 AI 답변 생성이 시작됩니다.

답글 및 추가 질문

질문 상세 화면에서 답글을 추가할 수 있습니다. 답글에도 AI 답변을 요청할 수 있으며, AI는 이전 대화의 맥락을 참고하여 연속적인 답변을 제공합니다.

AI 답변은 백그라운드에서 생성됩니다. 생성 중에는 로딩 표시가 나타나며, 완료되면 자동으로 화면에 표시됩니다.
07

검색

좌측 사이드바 상단의 검색창에서 키워드를 입력하면 프로젝트, 입력 데이터, AI 분석 결과를 통합 검색합니다.

검색 대상설명
프로젝트명 / 설명프로젝트 이름이나 설명에 검색어가 포함된 경우
모듈 입력 데이터각 단계에 직접 입력한 텍스트 내용
AI 분석 결과AI가 생성한 분석 보고서 내용
검색 결과는 연관도 순으로 정렬되며, 검색어 주변 내용이 발췌문으로 표시됩니다. 내가 소유한 프로젝트와 공개된 프로젝트가 모두 검색됩니다.
